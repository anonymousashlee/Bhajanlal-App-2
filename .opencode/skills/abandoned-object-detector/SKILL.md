# Abandoned Object Detector

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when identifying stationary foreground objects left unattended for configurable durations.

## Workflow

1. Maintain background model and foreground blobs.
2. Track stationary objects over time.
3. Associate with nearby persons (owner).
4. Trigger alert after duration threshold.
5. Handle occlusions and scene changes.

## Output

Abandoned object detection.
