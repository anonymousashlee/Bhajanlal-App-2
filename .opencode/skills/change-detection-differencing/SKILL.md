# Change Detection Differencing

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when computing pixel-wise temporal deltas to highlight deforestation or new construction.

## Workflow

1. Co-register images.
2. Normalize radiometry.
3. Compute difference metrics.
4. Threshold change pixels.
5. Classify change types.

## Output

Change detection map.
