# Epipolar Geometry Matching

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when the same car/person must be cross-referenced across overlapping cameras.

## Workflow

1. Estimate fundamental matrix.
2. Match points along epipolar lines.
3. Cross-reference detections.
4. Validate multi-camera tracking.

## Output

Cross-camera matched frames.
