# MPRNet (Multi-Stage Progressive Restoration)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when blurry moving objects must be progressively sharpened.

## Workflow

1. Stage 1 coarse restoration, stage 2 refinement.
2. Share features across stages with supervision.
3. Use for motion and defocus blur.
4. Inspect intermediate outputs for stability.

## Output

Progressively sharpened frames.
