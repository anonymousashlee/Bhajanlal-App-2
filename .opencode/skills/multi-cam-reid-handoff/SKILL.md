# Multi-Cam ReID Handoff

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when stitching movement timelines of the same person or vehicle across adjacent cameras.

## Workflow

1. Extract ReID embeddings.
2. Match across camera views.
3. Build global timelines.
4. Handle handoff gaps.
5. Visualize tracks.

## Output

Cross-camera ReID timelines.
