# GDPR Access Log Auditor

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when tracking and logging every user view or download of recorded surveillance footage.

## Workflow

1. Instrument view/download events.
2. Store audit logs immutably.
3. Generate access reports.
4. Alert on anomalies.
5. Support data subject requests.

## Output

GDPR-compliant access audit trail.
