# Auto-Gain Control (AGC) Normalization

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when sudden brightness flicker from clouds must be prevented.

## Workflow

1. Estimate scene brightness over time.
2. Smooth gain changes temporally.
3. Clamp gain range.
4. Validate on aerial views.

## Output

Flicker-free normalized frames.
