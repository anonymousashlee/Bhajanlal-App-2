# cloud-mask-segmentation

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when automatically hiding or making semi-transparent thick cloud patches blocking satellite terrain.

## Workflow

1. Segment cloud patches.
2. Mask or fade them.
3. Preserve terrain.
4. Validate visibility.

## Output

Cloud-masked terrain.
