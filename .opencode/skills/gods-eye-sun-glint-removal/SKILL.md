# Sun Glint Removal

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when specular solar reflections off windshields/pavement must be suppressed.

## Workflow

1. Detect saturated glint regions.
2. Inpaint or attenuate glint.
3. Preserve vehicle structure.
4. Validate on wet roads.

## Output

Glint-suppressed frames.
