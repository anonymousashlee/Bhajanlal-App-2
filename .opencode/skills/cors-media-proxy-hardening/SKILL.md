# cors-media-proxy-hardening

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when preventing proxy compression or downscaling when relaying external municipal camera images.

## Workflow

1. Disable compression in proxy.
2. Set correct Content-Type.
3. Add CORS headers.
4. Validate full-res relay.

## Output

Lossless media proxy relay.
