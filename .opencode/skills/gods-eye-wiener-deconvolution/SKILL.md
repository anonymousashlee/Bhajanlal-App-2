# Wiener Deconvolution

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when frequency-domain inverse filtering with an estimated PSF is needed.

## Workflow

1. Estimate the point spread function (PSF).
2. Apply Wiener filter in frequency domain.
3. Tune noise-to-signal ratio.
4. Avoid amplifying noise in flat regions.

## Output

Wiener-deconvolved frames.
