# AIS/ADS-B Track Correlator

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when fusing satellite imagery detections with maritime AIS or aviation ADS-B transponder logs.

## Workflow

1. Load detection and track data.
2. Match by time/location.
3. Resolve identities.
4. Build fused tracks.
5. Report correlations.

## Output

Fused AIS/ADS-B tracks.
