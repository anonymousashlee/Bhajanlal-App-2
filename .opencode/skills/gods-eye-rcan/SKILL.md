# RCAN (Residual Channel Attention Networks)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when channel attention must focus compute on high-frequency textures like grilles and limbs.

## Workflow

1. Insert channel attention blocks to weight informative feature maps.
2. Use long and short skip connections to stabilize very deep networks.
3. Tune reduction ratio to balance accuracy and latency.
4. Inspect attention maps to confirm focus on vehicle and human textures.

## Output

Attention-refined super-resolution emphasizing fine textures.
