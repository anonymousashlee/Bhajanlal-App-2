# cctv-aspect-ratio-correction

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when fixing stretched or squished municipal traffic camera feeds using metadata aspect detection.

## Workflow

1. Detect aspect ratio from metadata.
2. Apply correct aspect to video plane.
3. Avoid stretching.
4. Validate geometry.

## Output

Correct-aspect CCTV feeds.
