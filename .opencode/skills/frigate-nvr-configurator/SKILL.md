# Frigate NVR Configurator

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when generating and validating YAML configurations for Frigate NVR object detection and zones.

## Workflow

1. Define cameras, roles, and stream inputs.
2. Configure detectors and model paths.
3. Set zones, masks, and object filters.
4. Validate YAML and test detection.
5. Tune retention and recording policies.

## Output

Validated Frigate NVR configuration.
