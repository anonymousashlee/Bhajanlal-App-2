# Nighttime Low-Light Enhancement (LLIE)

Part of the **Bhajanlal** model-building skill library. Pillar: 103. Satellite & Aerial Remote-Sensing Imaging (100 skills)

Use when boosting signal-to-noise ratio under streetlamps using zero-reference deep curves.

## Workflow

1. Estimate the illumination curve without a reference (zero-reference deep LLIE).
2. Enhance brightness while suppressing the noise it reveals.
3. Preserve color so sodium streetlight casts do not skew band ratios.
4. Check that dark road edges and figures remain resolvable.

## Output

Night scene with usable contrast and controlled noise.
