# Backlight Compensation (BLC)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when foreground must be boosted facing low-angle sun.

## Workflow

1. Detect backlight condition.
2. Boost foreground exposure.
3. Avoid blowing out background.
4. Validate subject visibility.

## Output
