# Soil Moisture SAR Estimator

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when correlating C-band radar backscatter with topsoil moisture levels.

## Workflow

1. Calibrate SAR backscatter.
2. Apply moisture retrieval model.
3. Validate with ground sensors.
4. Map soil moisture.
5. Handle vegetation effects.

## Output

Soil moisture estimates.
