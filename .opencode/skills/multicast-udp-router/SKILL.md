# Multicast UDP Router

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when optimizing local network multicast settings to prevent packet loss across multi-camera setups.

## Workflow

1. Enable IGMP snooping on switches.
2. Assign unique multicast groups per camera.
3. Set TTL and socket buffers appropriately.
4. Monitor packet loss and jitter.
5. Document network topology and group map.

## Output

Loss-minimized multicast video distribution.
