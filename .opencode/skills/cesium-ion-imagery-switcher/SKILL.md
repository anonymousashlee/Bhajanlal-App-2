# cesium-ion-imagery-switcher

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when building seamless runtime switching between Bing Aerial, Esri World Imagery, and Sentinel layers.

## Workflow

1. Register each imagery provider with Cesium Ion.
2. Build a UI control to switch providers at runtime.
3. Preserve camera view and terrain during switch.
4. Handle missing tiles gracefully.

## Output

Seamless runtime imagery layer switching.
