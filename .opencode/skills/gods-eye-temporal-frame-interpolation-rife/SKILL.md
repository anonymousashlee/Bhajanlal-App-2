# Temporal Frame Interpolation (RIFE)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

## Workflow

1. Estimate intermediate frames with RIFE.
2. Use for display and tracking continuity.
3. Avoid for forensic evidence - synthetic frames.
4. Validate motion plausibility.
