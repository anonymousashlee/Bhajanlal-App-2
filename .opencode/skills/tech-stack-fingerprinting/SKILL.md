# tech-stack-fingerprinting

Part of the **Bhajanlal** model-building skill library. Pillar: 106. Security, Pentesting & Compliance (100 skills)

Use when identifying web servers, frameworks, and CMS versions on targets.

## Workflow

1. Fingerprint headers, cookies, and paths.
2. Match against known signatures.
3. Identify CMS/framework versions.
4. Map to known CVEs.

## Output

Technology stack profile.
