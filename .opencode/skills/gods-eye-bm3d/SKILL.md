# BM3D (Block-Matching and 3D Filtering)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when a gold-standard classical sparse-domain denoiser is required.

## Workflow

1. Group similar 2D blocks into 3D stacks.
2. Apply collaborative 3D transform and shrinkage.
3. Aggregate estimates back to the image.
4. Use for offline high-quality denoising.

## Output

High-quality classically denoised frames.
