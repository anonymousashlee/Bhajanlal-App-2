# Color Constancy (Gray World / White Patch)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when sodium-vapor casts must be corrected for car color ID.

## Workflow

1. Estimate illuminant via gray-world/white-patch.
2. Correct colors to neutral illuminant.
3. Validate car color accuracy.
4. Avoid over-correction on night scenes.

## Output
