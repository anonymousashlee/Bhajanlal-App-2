# Soft-NMS / Weighted Boxes Fusion (WBF)

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when overlapping boxes in dense traffic must be merged without suppressing adjacent pedestrians.

## Workflow

1. Apply Soft-NMS or WBF.
2. Merge overlapping detections.
3. Preserve adjacent pedestrians.
4. Validate on dense traffic.

## Output

Merged clean detections.
