# Shadow Detection & Illumination Recovery

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when cast building shadows must be normalized.

## Workflow

1. Detect shadow regions via color/texture.
2. Recover illumination in shadowed areas.
3. Avoid over-brightening non-shadow regions.
4. Validate pedestrian visibility in shadows.

## Output

Shadow-normalized frames.
