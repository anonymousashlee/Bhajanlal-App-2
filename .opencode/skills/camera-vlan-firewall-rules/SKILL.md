# Camera VLAN Firewall Rules

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when generating iptables/nftables rules isolating IoT cameras from internet access.

## Workflow

1. Define VLAN and subnets.
2. Generate firewall rules.
3. Block outbound internet from cameras.
4. Allow NVR/management access.
5. Test and document rules.

## Output

Firewall rules isolating cameras.
