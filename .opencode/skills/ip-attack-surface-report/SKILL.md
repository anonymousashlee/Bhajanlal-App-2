# ip-attack-surface-report

Part of the **Bhajanlal** model-building skill library. Pillar: 107. Email, Social Media & IP OSINT Security (199 skills)

1. Confirm written authorization and defined scope before any active testing.
2. Aggregates IP, ASN, port, and certificate findings into a prioritized remediation plan.
3. Document findings with evidence and impact.
4. Remediate, then re-test to confirm the fix.
