# Headlight Glare / Bloom Suppression

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when saturated specular highlights from car headlights must be masked.

## Workflow

1. Detect saturated glare regions.
2. Inpaint or attenuate glare.
3. Preserve headlight as a vehicle cue.
4. Validate on night traffic.

## Output

Glare-suppressed night frames.
