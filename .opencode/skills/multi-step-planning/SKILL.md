# multi-step-planning

Part of the **Bhajanlal** model-building skill library. Pillar: 108. Reasoning, Intent & Chain-of-Thought (20 skills)

Use when decomposing complex tasks into ordered, verifiable milestones.

## Workflow

1. Decompose into milestones.
2. Order by dependency.
3. Verify each step.
4. Deliver result.

## Output

Structured task execution.
