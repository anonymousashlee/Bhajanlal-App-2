# GeoParquet Converter

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when converting shapefiles and GeoJSONs into partitioned GeoParquet for DuckDB spatial queries.

## Workflow

1. Read source vectors.
2. Convert to GeoParquet.
3. Partition by region/time.
4. Validate with DuckDB.
5. Document schema.

## Output

GeoParquet datasets.
