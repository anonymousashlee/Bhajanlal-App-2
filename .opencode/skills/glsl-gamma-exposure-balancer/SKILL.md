# glsl-gamma-exposure-balancer

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when adding real-time brightness, gamma, and saturation controls per feed.

## Workflow

1. Add brightness/gamma/saturation uniforms.
2. Expose per-feed sliders.
3. Apply in shader.
4. Validate.

## Output

Per-feed exposure controls.
