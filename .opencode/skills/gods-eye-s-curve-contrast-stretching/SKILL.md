# S-Curve Contrast Stretching

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when mid-tone separation must be expanded.

## Workflow

1. Apply sigmoid S-curve to intensities.
2. Tune midpoint and slope.
3. Expand separation where asphalt and clothing overlap.
4. Avoid clipping highlights/shadows.

## Output

Mid-tone-separated frames.
