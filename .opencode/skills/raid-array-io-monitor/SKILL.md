# RAID Array I/O Monitor

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when monitoring disk write latency and IOPS bottlenecks on dedicated NVR servers.

## Workflow

1. Collect SMART and I/O stats.
2. Track latency and IOPS per disk.
3. Detect degraded arrays.
4. Alert on thresholds.
5. Report trends.

## Output

RAID I/O health monitoring.
