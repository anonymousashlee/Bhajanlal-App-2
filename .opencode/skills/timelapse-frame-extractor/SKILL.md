# Timelapse Frame Extractor

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when sampling one frame per minute from 24/7 footage and stitching daily MP4 summaries.

## Workflow

1. Sample frames at configured interval.
2. Filter by time of day if needed.
3. Stitch into daily MP4.
4. Add timestamps and watermark.
5. Archive and notify.

## Output

Daily timelapse MP4 summaries.
