# PMTiles Vector Tile Generator

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when building serverless cloud-hosted vector tilesets using Tippecanoe and PMTiles.

## Workflow

1. Prepare GeoJSON/MBTiles.
2. Run Tippecanoe.
3. Convert to PMTiles.
4. Upload to storage.
5. Serve and validate.

## Output

Serverless vector tileset.
