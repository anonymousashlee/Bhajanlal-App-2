# Orthorectification

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when terrain tilt and relief displacement must be removed from oblique aerial imagery.

## Workflow

1. Use DEM to correct terrain displacement.
2. Project to orthographic view.
3. Preserve ground features.
4. Validate on oblique aerials.

## Output

Orthorectified aerial frames.
