# webgl-fxaa-msaa-antialiasing

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when configuring multi-sample anti-aliasing to eliminate jagged lines on 3D models and HUD reticles.

## Workflow

1. Enable MSAA/FXAA.
2. Tune sample count.
3. Apply to scene.
4. Validate smooth lines.

## Output

Anti-aliased 3D/HUD lines.
