# dns-enumeration

Part of the **Bhajanlal** model-building skill library. Pillar: 106. Security, Pentesting & Compliance (100 skills)

Use when auditing DNS records, zone transfers, and misconfigured CNAMEs.

## Workflow

1. Enumerate A/AAAA/MX/TXT/CNAME records.
2. Test zone transfers (AXFR).
3. Detect dangling CNAMEs and takeover risks.
4. Document misconfigurations.

## Output

DNS audit findings.
