# Rolling Shutter Rectification

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when CMOS line-by-line readout skew on fast cars must be corrected.

## Workflow

1. Estimate per-row displacement from motion.
2. Warp rows to a common time reference.
3. Handle global and rolling shutter jointly.
4. Validate on fast-moving vehicles.

## Output

Rolling-shutter-corrected frames.
