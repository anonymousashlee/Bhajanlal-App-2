# False Color Band Visualizer

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when rendering NIR-Red-Green or SWIR composites to highlight vegetation and burn scars.

## Workflow

1. Select bands.
2. Normalize and composite.
3. Apply colormaps.
4. Visualize results.
5. Export images.

## Output

False-color composites.
