# RTMP Ingest Server

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when setting up Nginx-RTMP endpoints for remote cellular or edge camera uploads.

## Workflow

1. Install and configure nginx-rtmp module.
2. Define application endpoints and stream keys.
3. Enable recording and HLS repackaging.
4. Secure with stream-key auth or token validation.
5. Monitor ingest health and bandwidth.

## Output

RTMP ingest endpoint accepting edge uploads.
