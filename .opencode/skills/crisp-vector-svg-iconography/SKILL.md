# crisp-vector-svg-iconography

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when replacing blurry raster glyphs with razor-sharp SDF icons in Cesium.

## Workflow

1. Replace raster with SDF SVG.
2. Render crisp at any scale.
3. Validate icons.

## Output

Crisp SDF icons.
