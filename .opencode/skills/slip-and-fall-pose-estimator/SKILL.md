# Slip and Fall Pose Estimator

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when using keypoint pose estimation to detect sudden falls in healthcare or warehouse settings.

## Workflow

1. Run pose estimation per frame.
2. Compute body orientation and velocity.
3. Detect sudden fall patterns.
4. Trigger alerts and save clips.
5. Reduce false positives via context.

## Output

Fall detection via pose estimation.
