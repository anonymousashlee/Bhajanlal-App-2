# Sentinel Hub Downloader

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when automating multi-band GeoTIFF downloads from Copernicus Data Space APIs.

## Workflow

1. Authenticate with Copernicus.
2. Select collection and bands.
3. Download GeoTIFFs with retry.
4. Validate CRS and metadata.
5. Store organized by tile/date.

## Output

Downloaded Sentinel multi-band rasters.
