# Metric Scale Estimation

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when pixel dimensions must be mapped to real-world meters.

## Workflow

1. Estimate pixels-per-meter from known objects.
2. Map detector expected sizes.
3. Validate on cars and humans.
4. Improve small-object detection.

## Output

Metrically scaled frames.
