# Mosaic Seamline Blender

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when stitching adjacent satellite tiles with histogram matching and feathering.

## Workflow

1. Co-register tiles.
2. Compute seamlines avoiding features.
3. Apply histogram matching.
4. Blend with feathering.
5. Validate seams.

## Output

Seamless satellite mosaic.
