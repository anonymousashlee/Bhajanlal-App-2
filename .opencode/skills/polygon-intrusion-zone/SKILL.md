# Polygon Intrusion Zone

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when defining and testing region-of-interest (ROI) polygons for restricted area monitoring.

## Workflow

1. Define ROI polygons in camera coordinates.
2. Test point-in-polygon for each target.
3. Handle polygon updates at runtime.
4. Visualize zones for operators.
5. Log intrusions with snapshots.

## Output

ROI-based intrusion monitoring.
