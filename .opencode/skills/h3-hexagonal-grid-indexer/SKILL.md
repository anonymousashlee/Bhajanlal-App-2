# H3 Hexagonal Grid Indexer

Part of the **Bhajanlal** model-building skill library. Pillar: 112. Satellite & Geospatial Engineering (50 skills)

Use when aggregating point and raster data into Uber H3 spatial hexagons for fast analytics.

## Workflow

1. Convert coordinates to H3.
2. Aggregate data per hex.
3. Build hex grid layers.
4. Query and visualize.
5. Export results.

## Output

H3-aggregated spatial analytics.
