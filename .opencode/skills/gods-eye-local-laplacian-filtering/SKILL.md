# Local Laplacian Filtering

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

Use when multi-scale contrast must be manipulated without halos.

## Workflow

1. Build Laplacian pyramid.
2. Apply local tone mapping per level.
3. Reconstruct without halo artifacts.
4. Validate on high-contrast scenes.

## Output

Halo-free contrast-enhanced frames.
