# Camera Intrinsic Calibration & Lens Undistortion

Part of the **Bhajanlal** model-building skill library. Pillar: 104. God's Eye View - Image Clarity & Car/Human Detection (100 skills)

## Workflow

1. Calibrate intrinsics with checkerboard.
2. Undistort frames with distortion coefficients.
3. Validate straight lines.
4. Improve detection accuracy.
