# 3d-building-mesh-sharpening

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when tuning normals and lighting on extruded OSM and photorealistic building meshes.

## Workflow

1. Recompute or smooth mesh normals.
2. Tune lighting for edge definition.
3. Avoid over-brightening.
4. Validate building crispness.

## Output

Sharper 3D building meshes.
