# glsl-unsharp-mask-filter

Part of the **Bhajanlal** model-building skill library. Pillar: 105. God's Eye View - OpenCode Cesium/GLSL/Node Skills (100 skills)

Use when writing a custom Cesium PostProcessStage unsharp mask to crisp up blurry satellite tiles.

## Workflow

1. Create PostProcessStage with unsharp mask.
2. Tune radius and amount.
3. Apply to tiles.
4. Validate sharpness.

## Output

Unsharp-masked satellite tiles.
