# VLM Scene Describer

Part of the **Bhajanlal** model-building skill library. Pillar: 111. CCTV & Video Surveillance Engineering (50 skills)

Use when sending keyframe snapshots to a Vision-Language Model for natural-language incident summaries.

## Workflow

1. Select keyframes on events.
2. Send to VLM with prompt.
3. Parse and store summaries.
4. Attach to incident records.
5. Review for accuracy.

## Output

Natural-language incident summaries.
