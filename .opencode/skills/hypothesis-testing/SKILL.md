# hypothesis-testing

Part of the **Bhajanlal** model-building skill library. Pillar: 108. Reasoning, Intent & Chain-of-Thought (20 skills)

Use when listing and testing root-cause hypotheses ranked by probability.

## Workflow

1. List top hypotheses.
2. Test the cheapest first.
3. Update probabilities with evidence.
4. Conclude with the verified cause.

## Output

Hypothesis-driven diagnosis.
